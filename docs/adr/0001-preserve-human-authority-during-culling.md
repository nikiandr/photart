# Preserve human authority during culling

Photart copies every source photograph into the catalog before review and uses technical analysis only to prioritize attention and explain possible issues. Technical findings never select, reject, archive, or purge a photograph: those decisions belong to the photographer. At the end of culling, Photart defaults rejected photographs to reversible archival and offers permanent purging only as a secondary, explicit choice, accepting higher storage use in exchange for creative control and user trust.
