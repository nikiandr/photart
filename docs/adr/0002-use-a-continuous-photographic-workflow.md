# Use a continuous photographic workflow

Photart follows one connected progression from source selection through complete import, automatic technical analysis, culling, and gallery browsing. Culling and gallery browsing may use related darkroom and photobook atmospheres, but they are not separate Lightroom-style modules that require manual back-and-forth navigation. The visual environment changes as the photographer advances naturally through the work, preserving momentum at the cost of some module-level flexibility.
