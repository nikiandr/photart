# Stop before pixel editing

Photart imports, analyzes, compares, organizes, reviews, archives, and hands off photographs, but it does not develop, retouch, or generate imagery. Its purpose is to help the photographer reveal strong work from a large Shoot and carry that Selection into a downstream creative workflow. This deliberately gives up an all-in-one Lightroom-style product in order to keep Photart focused, preserve the originals, and avoid substituting software output for photographic authorship.
