# Photo import samples

`raw/` contains the six unmodified camera files used to evaluate RAW import.
Select `samples/raw` as a source folder when testing RAW support in Photart.
These files are not part of the automated test suite.

All six files are from [raw.pixls.us](https://raw.pixls.us/) and are listed
there under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Their original metadata is intact, including any embedded GPS data.
